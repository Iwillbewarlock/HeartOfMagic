# Heart of Magic - 흑염 달구기 (Heart of Magic - Black Flame) 1.0.0

- 제작자: Iwillbewarlock
- 기반 모드: Heart of Magic Librarian (제작자: Iwillbewarlock). Dinkel Zombie의 Heart of Magic - Spell Learning System을 다시 만든 모드입니다.

## 모드 소개

허리 왼쪽 앞에 차는 **사엘의 철창 등불**(Saeel's Iron Cage Lantern) 아이템 하나를 추가합니다. 철창 안에 잿빛이 감도는 검은 불꽃이 떠 있는 모습이며, 주변을 밝히는 빛은 내지 않습니다.

등불을 착용하면 **갈망**(Longing) 효과가 적용되며 다음 변화가 일어납니다.

1. 플레이어가 쓰는 화염 마법이 잿빛이 도는 검은색으로 바뀝니다. 투사체, 폭발, 손의 시전 이펙트, 몸을 감싸는 오라, 적중한 대상에 붙는 불꽃, 시전 광원이 모두 바뀝니다. 여기서 화염 마법은 Heart of Magic의 마법 카탈로그가 화염으로 분류한 일반 마법을 뜻합니다. 완전한 칠흑색이 아니라 은은하게 빛나는 잿빛 검은 불꽃입니다.
2. 화염 키워드가 있는 화염 마법은 매지카 소모량이 30% 늘어납니다. Heart of Magic 카탈로그에서만 화염으로 분류된 마법은 소모량이 늘어나지 않을 수 있습니다.
3. 화염 마법이 적중하면 **흑염**(Black Flame) 피해가 추가됩니다. 저항을 무시하고 2초 동안 대상 최대 체력의 2%만큼 피해를 줍니다. 다시 적중하면 중첩되지 않고 2초 지속시간이 처음부터 다시 시작됩니다. 마법 자체의 원래 피해는 평소처럼 저항의 영향을 받습니다. 망토 마법, 두루마리, 지팡이, 외침, 권능에는 적용되지 않습니다.
4. AE 1.6.1170과 1.7.104 버전(1.7.104는 게임 내 미테스트)에서는 등불을 착용한 채 화염 마법으로 처치한 적에게 나타나는 Frozen Electrocuted Combustion (FEC)의 시체 화염도 잿빛으로 바뀝니다.

바뀌지 않는 요소:
- NPC의 화염 마법, 플레이어가 손에 든 횃불, 소환수가 자체적으로 쓰는 화염, 화염 함정은 바뀌지 않습니다.
- 투사체 속도, 사거리, 마법 자체의 피해량도 그대로 유지됩니다.
- 등불을 벗으면 화염 마법의 외형과 매지카 소모량이 원래대로 돌아옵니다.

작동 방식:
게임을 시작할 때 모드 파일에 포함된 작은 보조 프로그램이 현재 로드 오더(바닐라와 모드 모두)의 화염 시각 효과를 잿빛 복사본으로 따로 만듭니다. 플레이어의 화염 마법만 이 복사본을 쓰며, NPC와 다른 마법은 원본 파일을 그대로 씁니다.

## 필요한 것

- Skyrim Special Edition / Anniversary Edition. 실제 게임에서 테스트한 버전은 AE 1.6.1170뿐입니다(아래 게임 버전 표를 참고하세요). Skyrim VR은 지원하지 않습니다.
- 게임 버전에 맞는 SKSE.
- Address Library for SKSE Plugins.
- Heart of Magic Librarian 1.5.0 이상 (1.6.0에서 테스트 완료). 이 모드는 Heart of Magic이 마법을 스캔할 때 만드는 마법 카탈로그를 읽습니다. 1.5.0부터는 처음 시작할 때 카탈로그를 자동으로 만듭니다.
- Microsoft Visual C++ Redistributable 2015-2022 (x64). 보조 프로그램 실행에 필요합니다. 대부분의 스카이림 환경에는 이미 설치되어 있습니다.
- 선택 사항: Immersive Equipment Displays (IED). IED가 있으면 IED가 등불을 허리에 걸어 주며, 없으면 등불 자체의 착용 모델을 씁니다. IED를 쓸 때는 위치를 바꿀 수 있습니다. `SKSE\Plugins\HeartOfMagic_BlackFlame.json` 파일에 `"lanternIedPreset": "frontLeft"`, `"frontRight"`, `"backLeft"`, `"backRight"` 중 하나를 추가하세요(기본값은 `frontLeft`이며, 변경 후에는 게임을 다시 시작하세요).
- 디스크 공간: 생성되는 복사본과 작업 파일의 용량은 로드 오더에 따라 다릅니다. 제작자의 테스트 환경(모드 약 4,000개)에서는 총 2.6 GB 정도를 차지했습니다.

## 설치

1. Mod Organizer 2 (MO2) 또는 Vortex로 압축 파일을 설치하세요.
2. 다운로드 파일은 한국어판과 영어판이 있습니다. 둘 중 하나만 설치하세요. 파일 구성과 FormID는 같고 게임 내 텍스트만 다릅니다.
3. `HeartOfMagic_BlackFlame.esp`와 `HeartOfMagic_BlackFlame_Slots.esp` 플러그인 두 개를 모두 활성화하세요.
4. `SKSE\Plugins\HeartOfMagic_BlackFlame.json` 파일을 지우지 마세요. 파일이 없으면 배포판과 다른 내장 기본값이 적용됩니다. 실수로 지웠다면 모드를 다시 설치하세요.
5. 루즈 파일 캐시 모드(예: CRDW)를 쓴다면 설치하거나 업데이트한 뒤에 캐시를 다시 만드세요(Force rebuild). 이전 캐시는 새 파일을 인식하지 못합니다.

## 처음 실행할 때

- 게임을 실행하고 메인 메뉴에서 기다리세요. 처음 실행할 때는 잿빛 복사본을 만드느라 평소보다 시간이 더 걸립니다. 세이브를 불러오기 전에 메인 메뉴에서 기다리세요. 제작자 PC(RTX 3070)에서 1~2분 정도였고, PC가 느리거나 로드 오더가 크면 더 걸립니다. 다 됐다는 표시는 화면에 나오지 않습니다. 불러온 뒤에도 주황색인 마법은 다음 실행부터 잿빛이 됩니다.
- Heart of Magic에 아직 마법 카탈로그가 없다면 첫 실행 자동 스캔이 카탈로그를 먼저 만듭니다. Heart of Magic - Black Flame은 스캔이 끝날 때까지 기다립니다.
- Heart of Magic의 자동 스캔이 꺼져 있거나, 이미 저장된 트리가 있어서 자동으로 스캔하지 않는다면 Heart of Magic에서 전체 스캔을 직접 실행하세요.
- 카탈로그가 준비되기 전에 세이브를 불러오거나 새 게임을 시작하면 해당 세션에서는 모드가 설정되지 않습니다. 스캔을 끝내고 게임을 다시 시작하세요.
- AE 1.6.1170에서는 처음 실행했을 때부터 복사본이 바로 적용됩니다. 다른 게임 버전에서는 다음 실행부터 적용될 수 있으니 게임을 한 번 다시 시작하세요.
- 로드 오더가 크면 첫 실행 뒤에 일부 마법이 여전히 주황색으로 보일 수 있습니다. 게임을 한 번 더 다시 시작하세요.
- 이후 실행부터는 유효한 복사본을 그대로 다시 씁니다.
- 생성된 복사본이나 카탈로그를 다른 플레이어와 공유하지 마세요. 각자의 모드 파일에 맞춰 만들어진 파일입니다.

## 등불 얻기

- 게임 내 위치: **안질푼트 매장묘실**(Ansilvund Burial Chambers) 위층의 탁자 위에 있습니다. 등불 옆에서 연기가 피어오릅니다. 이미 그곳을 방문했던 세이브라도 다음에 다시 방문하면 등불이 나타납니다.
- 콘솔 명령: 콘솔에 한글을 입력할 수 있다면 `help 철창 4`로 FormID를 확인한 뒤 `player.additem <FormID> 1`을 입력하세요. 한글을 입력할 수 없다면 FormID를 직접 계산합니다. FormID는 `FE` + 모드 매니저에서 `HeartOfMagic_BlackFlame.esp`에 표시되는 3자리 ESL 번호 + `80D`입니다(예: ESL 번호가 `FD3`이면 `FEFD380D`).

## 알려진 제한 사항

- 불꽃은 완전한 칠흑색이 아니라 잿빛이 도는 검은색입니다.
- 적이 불타 죽을 때 나오는 화염은 주황색으로 남습니다. 게임 엔진에 고정된 부분이라 바꿀 수 없습니다.
- 바닥의 룬 문양(Fire Rune)은 AE 1.6.1170과 1.7.104에서만 잿빛으로 바뀝니다(1.7.104는 게임 내 미테스트). 그을음 자국은 AE 1.6.1170에서만 확인했습니다.
- 장착하면 생기는 마법 오라(예: **화염 폭풍**)가 등불을 착용하거나 벗을 때 바로 갱신되는 기능은 AE 1.6.1170과 1.7.104에서만 작동합니다(1.7.104는 게임 내 미테스트).
- FEC 시체 화염은 일부 상황에서 주황색으로 남을 수 있습니다(예: 그 시체에 플레이어의 냉기나 전격 마법이 나중에 맞았을 때). 잿빛 시체 화염은 AE 1.6.1170과 1.7.104 전용입니다(1.7.104는 게임 내 미테스트).
- 등불을 착용한 상태에서 화염 마법을 들었다가 같은 장착 이펙트를 공유하는 비화염 마법으로 바꾸면, 그 마법의 광원에 색이 남아 있을 수 있습니다. 게임 진행에는 지장이 없으며 등불을 벗으면 원래대로 돌아옵니다.
- 화염처럼 보이는 마법이라도 Heart of Magic 카탈로그에 없으면 원래 모습을 유지합니다. 화염 마법과 비화염 마법이 공유하는 이펙트도 원래 모습을 유지할 수 있습니다.
- 등불을 착용한 상태에서 시작된 화상 이펙트는 도중에 등불을 벗더라도 끝날 때까지 잿빛으로 유지됩니다.
- 인벤토리 미리보기에서는 등불 안의 불꽃이 보이지 않을 수 있습니다(미리보기는 파티클을 그리지 않습니다). 정상적인 현상입니다.
- IED를 쓸 때 동료가 등불을 착용해도 외형이 표시되지 않습니다(플레이어에게만 설정되어 있습니다).

## 삭제

1. IED를 쓴다면 모드를 지우기 전에 등불을 벗고 저장하세요. 그렇지 않으면 IED가 등불의 마지막 상태를 계속 표시합니다.
2. 모드를 비활성화하고 삭제하세요. 플레이 도중에 플러그인을 제거하면 세이브에 흔적이 남을 수 있습니다. 모드를 설치하기 전의 세이브를 보관해 두세요.
3. 생성된 파일들을 삭제하세요.
   - MO2의 Overwrite 폴더(MO2를 쓰지 않는다면 게임의 Data 폴더): `meshes\heartofmagic\blackflame\copies` 및 `textures\heartofmagic\blackflame\copies`
   - 작업 폴더: `Documents\My Games\Skyrim Special Edition\SKSE\HeartOfMagic_BlackFlame` (GOG 버전: `Skyrim Special Edition GOG`)
   - 세이브 폴더의 `HoMBF_slots*.json` (MO2 프로필별 세이브를 쓴다면 해당 프로필의 saves 폴더)
   - 위 SKSE 폴더의 `HeartOfMagic_BlackFlame.log`, `HeartOfMagic_BlackFlame_tester.txt` (로그 파일입니다. 버그를 알려 주실 때 첨부해 주세요)

- Dinkel Zombie - 원작 Heart of Magic 제작.
- HDharder - Temp File Framework (GPL-3.0): 게임 실행 중에 새 파일을 인식시키기 위해 게임 파일 인덱스에 관한 조사 결과(함수 주소, 시그니처, 데이터 레이아웃)를 참고했습니다. 코드는 사용되지 않았습니다.

- GiraPomba - Lights On - Wearable Lanterns for IED: IED 허리 위치 값을 등불의 위치 프리셋으로 사용했습니다.
- powerofthree - 주소 참고 자료 제공 및 Frozen Electrocuted Combustion(이 모드에서 시체 이펙트를 잿빛으로 바꾸는 대상 모드) 제작.
- Ershin - Open Animation Replacer, Precision, True Directional Movement에서도 쓰이는 메인 스레드 훅 위치 참고.
- Khajiitistan - Black Flame (Nexus mod 192777): 외형 색감 참고. 해당 모드의 파일은 사용되지 않았습니다.
- MuIF와 KillFeed 제작자 - SE 1.5.97 충돌 처리 위치의 호출 오프셋 참고.
- Community Shaders - 팔레트 규칙을 정할 때 이펙트 셰이더를 참고했습니다.
- Bethesda - 잿빛 이펙트 메쉬는 스카이림 원본 파일로 만들었습니다.
- 라이브러리: CommonLibSSE-NG (GPL-3.0 with exceptions), nifly (GPL-3.0), DirectXTex, DirectX Tool Kit, DirectXMath, spdlog, {fmt}, JSON for Modern C++ (모두 MIT).
