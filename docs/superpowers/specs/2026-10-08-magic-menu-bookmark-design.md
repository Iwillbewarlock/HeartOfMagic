# 마법 메뉴 책갈피 — 설계

날짜: 2026-10-08. 상태: **구현됨, 게임 확인 전** (계획: docs/superpowers/plans/2026-10-08-magic-menu-bookmark.md. 사용자가 게임 확인을 줄이려고 1단계 진단 결과를 기다리지 않고 전부 만들게 함: 모르는 값은 코드가 게임 안에서 찾거나 대신할 것을 쓴다).
목업: 대화 안의 그림 두 장(책갈피 A안, 이름 옆 태그와 경험치 고리 1안).

## 1. 목적

- 마법 메뉴에서 Heart of Magic을 바로 연다. 단축키를 몰라도, 단축키를 꺼 둬도 열 수 있게 한다.
- 고른 주문의 사서 태그와 학습 경험치를 마법 메뉴에서 바로 보여 준다. 패널을 열지 않아도 된다.
- 단축키를 아예 안 쓰는 설정을 둔다. 넥서스 제보(Ramonopoly)처럼 글자 키를 단축키로 두면, 검색창에 글자를 칠 때 패널이 닫히는 일도 막는다.

## 2. 무엇이 보이나

### 2.1 책갈피 (2026-10-08 변경: 가죽 클립)
- 사용자가 준 참고 사진(책장 위 모서리를 접어 끼우는 가죽 클립 책갈피)처럼, 설명 칸 오른쪽 위 모서리에 접어 끼운 황갈색 가죽 클립. 접힌 선 아래 박음질, 앞날개에 "Heart of Magic" 음각(영문). 붉은 바탕·심장 문양 안(A안)은 버렸다.
- 그림 두 장(`Interface/HeartOfMagic/bookmark.dds`, 마우스용 금빛 글자 `bookmark_glow.dds`, Gemini 그림에서 만듦). 메뉴가 그림을 못 불러오면 같은 모양을 선과 글자 칸으로 그린다.
- 크기는 600 폭 설명 칸 기준 80, 칸 크기에 비례한다.
- 마우스를 올리면 4px쯤 솟고 글자가 금빛으로 빛난다(0.25초에 나타나 2초 주기로 숨 쉬듯, 떼면 사라짐).
- 누르면 마법 메뉴가 닫히고 패널이 열린다(3절).

### 2.2 이름 옆 태그와 경험치 고리 (1안)
- 설명 칸 제목(주문 이름) 왼쪽에 경험치 고리를 그린다. 지름은 이름 글자 높이의 약 1.6배이다.
  - 배우는 중: 파란 호. 채운 비율은 학습 진행도 `progressPercent`이다.
  - 마스터: 금색으로 가득 찬 원.
  - 아직 시작 안 함: 회색 빈 원.
  - 가운데 숫자: 진행도 %. 마스터면 숫자 없이 둔다.
- 이름 아래에는 태그 칩을 한 줄로 최대 4개까지 놓는다.
  - 고르는 규칙은 패널 주문 카드와 같다(`spellCard.js`의 칩 순서).
  - 넘치는 태그는 "+2"처럼 줄여 쓴다.
- 트리에 없는 주문(권능, 능력, 스크롤 사본, 트리가 아직 없는 경우)에는 고리와 칩을 붙이지 않는다. 제목은 원래대로 둔다.
- 다른 주문을 고르면 고리와 칩도 바뀐다. 메뉴가 설명 칸을 다시 채우는 순간을 따라간다(4.3절).

## 3. 동작

- **열기:** 책갈피를 누르면 마법 메뉴를 닫고(`UIMessageQueue`, `MagicMenu` 숨김) 패널을 연다(`UIManager::ShowPanel`). 책갈피로 열었다는 표시를 남긴다(`m_openedFromMagicMenu`).
- **닫기:** 그 표시가 있는 채로 패널이 닫히면(Esc, 단축키, 닫기 버튼 모두) 마법 메뉴를 다시 연다. 다시 열린 메뉴는 목록을 새로 읽으므로, 패널에서 새로 배운 주문이 바로 보인다.
  - 단축키로 연 경우는 지금처럼 게임으로 돌아간다.
- **학파 탭:** 다시 열린 메뉴가 마지막으로 보던 학파 탭을 기억하는지는 구현 1단계에서 확인한다. SkyUI는 기억하는 것으로 알려져 있다. 기억하지 않으면 지금 단계에서는 그대로 둔다.
- **게임패드:** 이번 범위가 아니다. 게임패드 사용자는 단축키로 연다.

## 4. 구조

### 4.1 어디에 붙이나: 스케일폼에 직접
- 메뉴 파일(SWF)은 배포하지도 고치지도 않는다.
- `MenuOpenCloseEvent`로 `MagicMenu`가 열리는 것을 받는다. 그 메뉴의 `uiMovie`에서 설명 칸 MovieClip을 찾아, 그 자식으로 빈 MovieClip을 만들고(`createEmptyMovieClip`) AS2 그리기 API(`beginFill`, `lineTo`, `curveTo`)로 책갈피와 고리를 그린다.
- 글자(퍼센트, 칩 이름)는 `createTextField`로 넣는다. 그러면 게임 메뉴 글꼴을 따라가고, 한국어 글꼴 모드를 쓰면 그 글꼴이 나온다.
- 클릭은 책갈피 클립의 `onRelease`에 네이티브 함수(`GFxFunctionHandler`)를 걸어서 받는다.
- 그림 파일(PNG/DDS)을 불러올 수 있으면 심장 문양만 그림으로 바꾼다. 구현 1단계에서 확인하고, 안 되면 선으로 그린다.
- PrismaUI로 덧씌우는 방식은 쓰지 않는다. 이유는 세 가지다. 화면 좌표를 메뉴 모드와 해상도마다 맞춰야 하고, 클릭을 받으려면 포커스를 가져가 메뉴 입력을 빼앗으며, CPU로 그리는 화면이 하나 더 생긴다.

### 4.2 설명 칸 찾기: 데이터 파일
- `SKSE/Plugins/SpellLearning/magicmenu_paths.json`: 설명 칸 경로 목록이다. 앞에서부터 차례로 찾는다.
  - 바닐라 경로와 SkyUI 경로를 1단계에서 게임으로 확인해서 채운다.
- 새 메뉴 모드는 경로 한 줄만 더하면 지원된다. 다시 빌드할 필요가 없다.
- 하나도 못 찾으면 아무것도 붙이지 않는다. `SpellLearning.log`에 "설명 칸을 못 찾음"과 메뉴 루트의 자식 이름들(2단계 깊이까지)을 남긴다. 메뉴가 깨지는 일은 없다.
- 책갈피 위치는 찾은 칸의 실제 폭과 높이(`_width`, `_height`)를 읽어 정한다.

### 4.3 고른 주문 따라가기
- 메뉴가 설명 칸을 다시 채울 때(주문 선택이 바뀔 때) 고리와 칩을 다시 그린다.
- 거는 지점(설명 칸의 갱신 함수를 감쌀지, 메뉴의 선택 이벤트를 받을지)은 1단계에서 SWF 구조를 보고 정한다.
- 어느 쪽이든 고른 주문의 FormID를 알아내야 한다.
  - 바닐라는 `MagicMenu`의 선택 항목에서 얻는다.
  - SkyUI는 목록 항목의 `formId`에서 얻는다.

### 4.4 데이터
- 경험치: `ProgressionManager::GetProgress(formId)`를 쓴다. 패널과 같은 값이다.
- 트리에 있는지: 진행 데이터나 저장된 트리에 그 주문이 있는지로 판단한다. 계획 단계에서 기존 조회 함수를 찾아 쓴다.
- 태그: 사서 카탈로그(`spell_catalog.json`, persistentId 키)에서 읽는다. 메뉴를 열 때가 아니라 카탈로그를 쓰거나 읽을 때 한 번 메모리에 둔다.
- 칩 이름: 패널 언어 파일의 `chips.*` 키를 쓴다. 13개 언어가 이미 있다. 읽는 방식은 `HudNotify::Configure`가 `hud.*`를 읽는 것과 같다(언어가 바뀔 때만 다시 읽음).

## 5. 설정

| 설정 | 키 (config.json) | 기본값 | 화면 |
|---|---|---|---|
| 단축키 없음 | `hotkeyCode: 0`, `hotkey: ""` | F8 (66) | 단축키 줄의 "없음" 버튼 |
| 마법 메뉴 책갈피 | `magicMenu.bookmark` | 켜짐 | 설정 > 일반의 스위치 |
| 이름 옆 태그와 고리 | `magicMenu.spellInfo` | 켜짐 | 같은 곳의 스위치 |

- 키 처리(`Main.cpp`의 `idCode != m_hotkeyCode`)는 그대로 둔다. 코드 0은 어떤 키에도 쓰이지 않으므로 "없음"이면 단축키가 반응하지 않는다.
- 글자 키(A~Z)를 단축키로 고르면 "검색창에 글자를 칠 때 패널이 닫힙니다" 경고를 띄운다. 막지는 않는다.
- **열 방법이 사라지는 것 막기:**
  - 단축키가 "없음"이면 책갈피 스위치를 끌 수 없다(회색으로 두고 이유를 적는다).
  - 책갈피가 꺼져 있으면 "없음" 버튼을 누를 수 없다.
  - config.json을 손으로 고쳐 둘 다 끈 경우에는, 불러올 때 책갈피를 켜고 로그에 남긴다.
- 새 문구는 13개 언어로 넣는다: 없음, 스위치 두 개와 설명, 글자 키 경고, 막힌 이유. 한국어는 용어집을 따른다.
- 설정 프리셋은 이 값들을 바꾸지 않는다. 단축키처럼 개인 설정으로 다룬다.

## 6. 파일

- 새 파일: `plugins/spelllearning/src/magicmenu/MagicMenuBookmark.cpp`(메뉴 열림 이벤트, 경로 찾기, 책갈피, 클릭), `MagicMenuSpellInfo.cpp`(고리와 칩), `include/magicmenu/MagicMenuBookmark.h`. 파일마다 600줄을 넘지 않게 나눈다.
- `SKSE/Plugins/SpellLearning/magicmenu_paths.json`을 새로 만든다. FOMOD와 `Distribution.cmake`에 넣는다.
- 고칠 곳:
  - `UIManagerCore.cpp`: `HidePanel`에서 마법 메뉴 다시 열기
  - `UIManagerConfig.cpp`, `UIManagerConfigSave.cpp`: 설정 키와 둘 다 꺼짐 보정
  - `Main.cpp`: 이벤트 등록
  - 패널 `settingsPanel.js`, `index.html`, `dev-harness-parts.html`
  - `lang/*.json` 13개
- 문서: ARCHITECTURE.md(새 시스템), DESIGN.md(설정 화면), TRANSLATING.md(키 수), CHANGELOG 1.4.0. 새 시스템이므로 CLAUDE.md 문서 결정 트리에도 넣는다.

## 7. 확인

- 1단계(게임, 코드 최소):
  - 바닐라와 SkyUI에서 설명 칸 경로와 선택 갱신 지점
  - 그림 파일을 불러올 수 있는지
  - 다시 연 마법 메뉴가 학파 탭을 기억하는지
  - 이 셋은 로그로 확인하고 결과를 이 문서에 적는다.
- 빌드, `node run-tests.js`. 새 JS(설정 막힘 규칙)는 테스트 모듈을 추가해서 확인한다.
- 게임에서 확인할 것:
  - 책갈피 표시, 마우스 올림, 클릭 → 패널 → 닫기 → 마법 메뉴
  - 주문을 바꿀 때 고리와 칩 갱신, 트리 밖 주문에는 표시 없음
  - 경로를 못 찾을 때의 로그
  - 단축키 없음, 둘 다 꺼짐 보정
- TAKEALOOK에 깔린 UI 모드에서도 한 번 확인한다.
