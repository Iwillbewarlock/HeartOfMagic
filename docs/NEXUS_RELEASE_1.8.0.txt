=====================================================================
1. Files tab - main file
=====================================================================

Name: Heart of Magic Librarian
Version: 1.8.0

Description:
Adds three mastery ranks for mastered spells (tracked per cast for a later version to build on, with no effect on spells yet), two-way casting practice and archetype memory exchange with Spell Research, and a faster game start. Fixes casting XP caps after lowered progress, direct-link XP when casting duplicate spells across plugins, book XP spent on a 100% target that is not unlocked yet, target priority in single learning mode, and script compatibility with Don't Eat Spell Tomes (LoreRim / Rite of Arcana) and the ISL patch. Requires the same as before (SKSE, Address Library, PrismaUI); your saves and saved tree keep working with no tree rebuild needed.

Debug Symbols file description (same version):
Optional. Puts function names into Crash Logger reports. Install it only if you want to send a crash log.

=====================================================================
2. Changelogs tab - version 1.8.0 (one line per entry)
=====================================================================

New: Mastery ranks - a spell you have mastered keeps growing, with every cast of it earning mastery XP toward three mastery ranks shown on its spell card ("Mastery rank 1/3" and a bar) and a corner message at each rank. A rank costs more for a higher-level spell (Novice 100 XP ... Master 1500 XP by default), and a higher skill in the spell's school gives more XP per cast (up to twice as much at 100), so a skill lowered later (Legendary) never takes a rank away. Only casting the mastered spell itself counts; the cast that masters a spell earns none, and relocking a spell or setting its XP so that it is no longer mastered (below 100% and not unlocked) clears it, while an unlocked spell whose XP cheat mode lowers keeps its ranks. The ranks have no effect on the spell yet: a later version builds on them. Settings > Learning > Mastery Ranks turns them off; the numbers are in `config.json`, `"mastery"`. Mods can read a spell's rank (Papyrus `SpellLearning.GetMasteryRank`, the C++ API version 3) and listen for `SpellLearning_MasteryRankUp`. Saved with the game in a record of its own: a save from before starts every spell at 0, and saving again with an older version of Heart of Magic drops the mastery XP (everything else stays). The card's and the setting's text is in all 13 panel languages.
New: Spell Research: practice and memory - with Spell Research installed and imported, casting a spell you are learning now also teaches Spell Research: every 15% of progress a cast crosses (and mastery) adds a short research session (25 research minutes by default) to the spell's Spell Research archetypes, by Spell Research's own research formula. The other way round, casting XP for a spell rises by up to 25% with how well you already know its archetypes at its level, measured on Spell Research's own spell-composing scale. Only casting counts (not tomes, passive learning or other mods). Both halves can be turned off and sized under Settings > Spell Tome Learning, below the Spell Research line (shown only with Spell Research installed); `config.json` `spellResearch.memoryExchange`. Both are off while cheat mode is on. The four setting labels are in all 13 panel languages. Each 15% step pays into Spell Research once per spell: a spell relocked or set back to 0 XP and practised again adds nothing (saved with the game; a save from before this version starts with nothing counted as paid).
Changed: Faster game start - the perk overhaul step at data load plans only over the spells a rule could pick, builds each spell's details once per effect, leaves out what it never reads, reads its files while the game loads and frees its memory in the background. The search for the spells vampires cast moved to the main menu, a few milliseconds a frame. The result is the same as before.
Fixed: XP that stopped coming after a spell's progress was lowered - each kind of casting XP (any spell, same school, a direct link) has a cap per spell, and the XP counted against those caps stayed where it was when cheat mode, a mod or a smaller required XP lowered the spell's progress, so a source at its cap gave nothing again. The counts are now kept as shares of the spell's required XP: they follow a lowered progress down (all cleared at 0 XP), and a required XP that changes (an override, the tree's number, a game load) neither reopens nor closes a cap. The save keeps the shares in a record of their own and still writes the counts the way 1.7.0 reads them, so going back keeps them. A save from 1.7.0 has its counts converted when it loads (each time a save comes back from 1.7.0), against the required XP known then, putting right any cap stuck by the old bug. For a spell learned downward that conversion can give back part of a used cap once - with the default settings up to 3.5% of the spell's XP for the any-spell cap, 10.5% same school, 35% direct link (the share and the caps are settings) - or close one a few percent early; from the next save on the counts are exact.
Fixed: Casting a copy of a linked spell - when two plugins carry the same spell, the tree keeps one; a copy you learned before (or elsewhere) now counts as that spell for the direct-link XP of the spells next to it in the tree, as it already did for their requirements, instead of counting as a same-school cast only.
Fixed: Book XP spent on a spell that could not take it - a learning target at 100% that is not unlocked yet (waiting for Unlock, or for ISL to teach it) took a skill book's XP as if it counted, so BookXP marked the book read and it gave nothing later. A grant now counts only what it really added (near the top, 99% plus 5 XP is 1 XP), mods' XP calls get that amount back, and the book stays unread for a spell that took nothing. In single learning mode a cast no longer spends its one target on such a spell.
Fixed: Single learning mode with more than one target - when a save holds targets in more than one school while the mode is "single" (switched after setting them, or set by a mod), a cast credited whichever target came first in memory. It now credits the closest one: the spell cast itself, then a direct link, then the same school, then any other.
Fixed: Don't Eat Spell Tomes and the mods that use it - with the real Don't Eat Spell Tomes installed (LoreRim, for Rite of Arcana), Heart of Magic no longer takes over its script functions, which previously caused a mod asking for spell tome events to register with Heart of Magic while Don't Eat Spell Tomes sent them, hearing nothing. With the ISL patch, whose file replaces Don't Eat Spell Tomes, Heart of Magic now provides all of its script functions, not only the two ISL calls (also the form, magic effect and reference alias registrations, the API version and sending the event), and an ISL patch from an earlier version is still recognised as Heart of Magic's.
